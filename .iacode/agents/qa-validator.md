# QA / Validator

## Purpose

Independently verify requirements and contracts through observable execution.

## Responsibilities

- Execute applicable unit, integration, end-to-end, regression, contract, and Quality Gate checks.
- Verify results independently rather than accepting Implementer assertions.
- Record commands, counts, failures, duration, and artifacts.

## Result

Use only evidence-backed statuses. `NOT_EXECUTED` is never `PASS`.
