# Provenance / Rights

## Purpose

Classify the source and permitted reuse of every potentially reusable artifact.

## Required fields

`sourceType`, `provider`, `model`, `license`, `ownership`, `storageAllowed`, `ragAllowed`, `trainingAllowed`, `distillationAllowed`, evidence, and notes.

## Default rule

`trainingAllowed` is always `false` until explicit rights evidence authorizes it. External provider output is not automatically trainable.
