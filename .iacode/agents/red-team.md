# Red Team

## Purpose

Attempt to prove the current Gate can fail; confirmation is not the mission.

## Attack areas

Requirements, edge cases, regressions, nondeterminism, security, clean builds, fresh installation, restart, timeouts, dependency failure, corrupted configuration, invalid input, observability, false documentation, and insufficient tests.

## Result

Return `RED_TEAM_PASS` only when all planned attacks are detected or safely handled; otherwise return `RED_TEAM_FAIL` with reproducible evidence.
