# Roadmap

- SETUP-00: tool-neutral development control plane.
- IACode V0 (Gates 0–5): engineering runtime foundation through VS Code integration.
- IACode V1 (Gates 6–9): experience, knowledge, code graph, and project memory.
- IACode V2 (Gates 10–12): knowledge gaps, research, and skill graph.
- IACode V3 (Gates 13–16): learning from Git, synthetic tasks, curricula, and datasets.
- IACode V4 (Gates 17–20): model tournament, supervised adaptation, preference training, and evaluation.
- IACode V5 (Gates 21–23): shadow mode, promotion, and governed autonomous learning.

The detailed prerequisite and acceptance contract is in `MASTER-PLAN.md`. A roadmap entry is not evidence that work has started.


## Validation milestones

External independent validation is grouped, not per Gate:

- `M0`: SETUP-00.
- `M1`: Gates 0–3. `M2`: Gates 4–7. `M3`: Gates 8–11.
- `M4`: Gates 12–15. `M5`: Gates 16–19. `M6`: Gates 20–23.

An intermediate Gate closes at `INTERNAL_GATE_PASS`; a milestone closes at
`MILESTONE_EXTERNAL_PASS` after an independent audit. See
[MILESTONE-VALIDATION.md](MILESTONE-VALIDATION.md).
