# Decisions

- Gate6 alone is explicitly authorized after sealed/validated/published Gate5; no predecessor is rewritten.
- ADR-0050 chooses source-bound explicit-consent capture and a pure domain library with API-owned SQL/source adapters.
- ADR-0051 bounds primary retention, automatic purge and minimal anti-resurrection tombstones.
- Unknown rights remain denial; no raw provider text/private reasoning or future knowledge/training behavior is accepted.
- Internal roles keep separate artifacts but are not independent validation. M2 and second-tool approval remain pending.
- Before acceptance, widen the functional evidence markers to all 37 existing runtime criteria
  (sections 2–7). The original 51 criteria, their descriptions and mandatory flags remain unchanged;
  entry and delivery obligations remain separately required. The previous single marked criterion
  was an instrumentation omission, not an accepted 1/1 functional proof. A root guard rejects a
  shrunk functional denominator. No future execution is represented as passing evidence.
- G6-INT-007 is a source-read boundary, not a demonstrated output disclosure: the actual SQL
  regression observes a whole task result column fetched before closed projection. Require
  raiseload column allowlists, SQL-side structured-byte limits and exact JSON scalar reads, then
  repeat real source capture. Preserve the diagnostic integration's false operational-identity
  flag as unproven; add before/after/missing identity receipts without relaxing that comparison.
- Runtime-v1 remains immutable and its incomplete full invocation cmd-0106 is preserved, not a
  failing test verdict or PASS. Cmd-0107 interrupts only the re-observed owned verifier/tree and
  awaits its original recorder before appending. Canonical Gate6 retrospective preparation must
  join the assurance source before the final complete run; add it with its template/lesson guard,
  then publish a new subject without amending a commit or moving v1. Later closure outcomes remain
  checkpoint-owned, so they need no future unverified in-scope narrative edit.
- The broad staged Git whitespace diagnostic reports original CRLF/trailing bytes in dedicated
  byte-preserving observations. Those originals are intentionally not reformatted; staged raw
  equality passed at cmd-0103, and the separate authored/non-observation diff check was clean.
  No complete Git whitespace PASS, detector relaxation or raw-observation normalization is claimed.
