# Model Usage Policy

Record the actual tool, provider, exposed model identity, tool version, effort exposure, and timestamps. Never infer a model version or reasoning effort that the environment did not expose.

External model output is an engineering input, not automatically training data. Store only what is necessary, redact sensitive material, classify provenance, and default training and distillation rights to false.

Future local-model evaluation and promotion must use held-out evidence, independent review, shadow mode, and explicit promotion criteria defined by later Gates.

The Gate 4 Quality Engine validates software projects; it is not the held-out model evaluation
system reserved for Gate 20. Project manifests, filenames, command output, findings and evidence are
untrusted data. They never become model instructions and cannot select a runner, image, sandbox
policy, denominator or verdict. If bounded quality summaries are later supplied to an agent, they
are labelled tool data with artifact references, not instructions or private reasoning.
